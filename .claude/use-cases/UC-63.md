# UC-63: View / Search Users

| Field | Value |
|---|---|
| ID | UC-63 |
| Feature | AUSR-01 |
| Group | User Management |
| Actor(s) | Admin |
| Data | Users |
| Business rules | [BR-02](../business-rules/BR-02.md), [BR-07](../business-rules/BR-07.md) |

## Description

An Admin views the user list and searches by name or email.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin opens the user list.
2. The Admin searches by name or email and/or filters by role and status.
3. The system returns a page of matching users with name, email, role, status and registration date.

## Alternative Flows

- **A1. No match**: At step 3, the list is empty.

## Notes

- Password hashes and tokens are never returned (BR-02).
