# UC-10: View Addresses

| Field | Value |
|---|---|
| ID | UC-10 |
| Feature | PROF-03 |
| Group | Profile & Address Book |
| Actor(s) | Customer |
| Data | UserAddresses |
| Business rules | [BR-08](../business-rules/BR-08.md), [BR-09](../business-rules/BR-09.md) |

## Description

A customer views their saved shipping addresses.

## Preconditions

- The customer is signed in.

## Main Flow

1. The customer opens the address book.
2. The system returns the customer's addresses, with the default address first.

## Alternative Flows

- **A1. No addresses**: At step 2, the system shows an empty address book with an option to add one (UC-11).
