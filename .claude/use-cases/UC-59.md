# UC-59: Activate / Deactivate Voucher

| Field | Value |
|---|---|
| ID | UC-59 |
| Feature | AVOU-02 |
| Group | Voucher Management |
| Actor(s) | Admin |
| Data | Vouchers |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-11](../business-rules/BR-11.md), [BR-26](../business-rules/BR-26.md) |

## Description

An Admin turns a voucher on or off.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin toggles a voucher.
2. The system saves `IsActive`.

## Alternative Flows

- None.

## Postconditions

- A deactivated voucher cannot be applied to new orders (BR-26); existing orders are not affected.
