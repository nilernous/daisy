# UC-53: View / Filter Orders

| Field | Value |
|---|---|
| ID | UC-53 |
| Feature | AORD-01 |
| Group | Order Management |
| Actor(s) | Admin, Staff |
| Data | Orders |
| Business rules | [BR-07](../business-rules/BR-07.md) |

## Description

Staff view all orders and filter by status, date and order code.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user opens the order list.
2. The user filters by order status, payment status, date range and/or `OrderCode`.
3. The system returns a page of matching orders, newest first.

## Alternative Flows

- **A1. No match**: At step 3, the list is empty.
