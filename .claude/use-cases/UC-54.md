# UC-54: View Order Detail (Admin)

| Field | Value |
|---|---|
| ID | UC-54 |
| Feature | AORD-02 |
| Group | Order Management |
| Actor(s) | Admin, Staff |
| Data | Orders, OrderItems, Users |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-28](../business-rules/BR-28.md) |

## Description

Staff view an order's items, amounts, payment and customer information.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user opens an order.
2. The system returns the order, item snapshots (BR-28), amounts, payment details including `TransactionCode`, and the customer's name, email and phone.

## Alternative Flows

- **A1. Order not found**: At step 1, the system returns 404 Not Found.

## Related Use Cases

- UC-55 Update Order Status
- UC-56 Cancel Order (Admin)
- UC-57 Update Payment Status
