# UC-03: Logout

| Field | Value |
|---|---|
| ID | UC-03 |
| Feature | AUTH-03 |
| Group | Authentication |
| Actor(s) | Customer, Staff, Admin |
| Data | Users |
| Business rules | [BR-04](../business-rules/BR-04.md) |

## Description

A signed-in user ends their session and the current refresh token is revoked.

## Preconditions

- The user is signed in.

## Main Flow

1. The user chooses Logout.
2. The system clears the stored refresh token and its expiry.
3. The client discards the access token and refresh token.
4. The user is signed out.

## Alternative Flows

- None.

## Postconditions

- The old refresh token can no longer be used.
