# UC-18: Sort Products

| Field | Value |
|---|---|
| ID | UC-18 |
| Feature | CAT-06 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Products |
| Business rules | [BR-14](../business-rules/BR-14.md), [BR-15](../business-rules/BR-15.md) |

## Description

A visitor sorts the product list by newest, price, best selling or rating.

## Preconditions

- None.

## Main Flow

1. The visitor chooses a sort option: newest, price ascending, price descending, best selling or rating.
2. The system returns the list in that order (BR-15).

## Alternative Flows

- None.

## Related Use Cases

- Can be combined with UC-16 and UC-17.
