# UC-25: View Wishlist

| Field | Value |
|---|---|
| ID | UC-25 |
| Feature | WISH-03 |
| Group | Wishlist |
| Actor(s) | Customer |
| Data | Wishlists, Products |
| Business rules | [BR-08](../business-rules/BR-08.md), [BR-10](../business-rules/BR-10.md), [BR-14](../business-rules/BR-14.md) |

## Description

A customer views their saved products.

## Preconditions

- The customer is signed in.

## Main Flow

1. The customer opens the wishlist.
2. The system returns the saved products, newest first, with thumbnail and effective price (BR-14).

## Alternative Flows

- **A1. Product hidden**: At step 2, a product that has been hidden is shown as unavailable (BR-10).
