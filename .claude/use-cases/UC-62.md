# UC-62: Show / Hide Review

| Field | Value |
|---|---|
| ID | UC-62 |
| Feature | AREV-02 |
| Group | Review Moderation |
| Actor(s) | Admin, Staff |
| Data | Reviews, Products |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-38](../business-rules/BR-38.md), [BR-39](../business-rules/BR-39.md) |

## Description

Staff hide a review that breaks the rules, or show it again.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user toggles a review's visibility.
2. The system saves `IsVisible` (BR-39).
3. The system recalculates the product's average rating and review count (BR-38).

## Alternative Flows

- None.

## Postconditions

- The review is shown or hidden and the product rating is updated.
