# UC-52: Low-stock Warning

| Field | Value |
|---|---|
| ID | UC-52 |
| Feature | INV-02 |
| Group | Inventory |
| Actor(s) | Admin, Staff |
| Data | ProductVariants |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-17](../business-rules/BR-17.md) |

## Description

Staff see the variants whose stock is at or below their warning threshold.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user opens the low-stock list.
2. The system returns active variants with `StockQuantity <= LowStockThreshold` (BR-17), lowest stock first, with product name, SKU, size, color and stock.

## Alternative Flows

- **A1. Nothing low on stock**: At step 2, the list is empty.

## Related Use Cases

- UC-51 Update Stock
