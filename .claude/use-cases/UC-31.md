# UC-31: Merge Guest Cart

| Field | Value |
|---|---|
| ID | UC-31 |
| Feature | CART-06 |
| Group | Shopping Cart |
| Actor(s) | System |
| Data | CartItems |
| Business rules | [BR-17](../business-rules/BR-17.md), [BR-20](../business-rules/BR-20.md), [BR-22](../business-rules/BR-22.md) |

## Description

When a guest logs in, the system moves their session cart into their user cart.

## Preconditions

- A guest with a session cart has just logged in (UC-02).

## Main Flow

1. The system loads the lines of the guest session.
2. For each line, if the user cart already has the same variant, the system adds the quantities together, capped at available stock; otherwise it moves the line to the user.
3. The system deletes the remaining guest lines.
4. The user sees one combined cart.

## Alternative Flows

- **A1. Guest cart empty**: At step 1, nothing happens.

## Postconditions

- No cart lines remain for the guest session (BR-22).

## Related Use Cases

- Included by UC-02 Login
