# UC-48: Manage Images

| Field | Value |
|---|---|
| ID | UC-48 |
| Feature | APRD-04 |
| Group | Product Management |
| Actor(s) | Admin, Staff |
| Data | ProductImages |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-16](../business-rules/BR-16.md) |

## Description

Staff upload product images, choose the thumbnail, reorder them and link them to a color.

## Preconditions

- The user is signed in as Staff or Admin and the product exists.

## Main Flow

1. The user uploads one or more images; the system stores the files and saves their URLs.
2. The user chooses one image as the thumbnail; the system clears the previous thumbnail (BR-16).
3. The user reorders the images; the system saves `SortOrder`.
4. The user links an image to a color (variant), or removes the link.
5. The user deletes an image; the system removes it.

## Alternative Flows

- **A1. Unsupported file**: At step 1, the system rejects files of an unsupported type or size.

## Postconditions

- The product gallery is updated.

## Notes

- See the note in BR-16 about color vs. variant.
