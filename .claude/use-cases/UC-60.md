# UC-60: View Voucher Usage

| Field | Value |
|---|---|
| ID | UC-60 |
| Feature | AVOU-03 |
| Group | Voucher Management |
| Actor(s) | Admin |
| Data | Vouchers, Orders |
| Business rules | [BR-07](../business-rules/BR-07.md) |

## Description

An Admin sees how many times a voucher was used and which orders used it.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin opens a voucher's usage.
2. The system shows `UsedCount` / `UsageLimit` and a page of the orders that used the voucher, with `OrderCode`, customer, date, discount amount and status.

## Alternative Flows

- **A1. Never used**: At step 2, the order list is empty.
