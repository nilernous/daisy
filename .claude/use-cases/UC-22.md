# UC-22: Flash Sale / Hot Deal

| Field | Value |
|---|---|
| ID | UC-22 |
| Feature | CAT-10 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Products |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-14](../business-rules/BR-14.md), [BR-15](../business-rules/BR-15.md) |

## Description

A visitor sees products whose sale is active now.

## Preconditions

- None.

## Main Flow

1. The visitor opens the Flash Sale section.
2. The system returns active products whose sale is active at the current time (BR-14).
3. Each product shows sale price, base price and the sale end time.

## Alternative Flows

- **A1. No active sale**: At step 2, the section is empty or hidden.
