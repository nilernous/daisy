# UC-39: Track Order Status

| Field | Value |
|---|---|
| ID | UC-39 |
| Feature | ORD-03 |
| Group | My Orders |
| Actor(s) | Customer |
| Data | Orders |
| Business rules | [BR-08](../business-rules/BR-08.md), [BR-35](../business-rules/BR-35.md) |

## Description

A customer follows the progress of an order: Pending -> Confirmed -> Shipping -> Completed.

## Preconditions

- The customer is signed in.

## Main Flow

1. The customer opens the status of one of their orders.
2. The system shows the current `OrderStatus` on the timeline (BR-35) with the stored times: created, paid, completed or canceled.

## Alternative Flows

- **A1. Order canceled**: At step 2, the system shows the cancellation time and reason.

## Related Use Cases

- The times of `Confirmed` and `Shipping` are not stored (BR-35).
