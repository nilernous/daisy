# UC-66: Change Role

| Field | Value |
|---|---|
| ID | UC-66 |
| Feature | AUSR-04 |
| Group | User Management |
| Actor(s) | Admin |
| Data | Users |
| Business rules | [BR-04](../business-rules/BR-04.md), [BR-07](../business-rules/BR-07.md) |

## Description

An Admin changes a user's role between Customer, Staff and Admin.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin chooses a new role for a user.
2. The system saves the new role (BR-07).
3. The new role takes effect when the user's next access token is issued (BR-04).

## Alternative Flows

- **A1. Changing own role**: At step 1, the system rejects the action so an Admin cannot remove their own Admin access.

## Postconditions

- The user has the new role.
