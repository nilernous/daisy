# UC-38: Order Detail

| Field | Value |
|---|---|
| ID | UC-38 |
| Feature | ORD-02 |
| Group | My Orders |
| Actor(s) | Customer |
| Data | Orders, OrderItems |
| Business rules | [BR-08](../business-rules/BR-08.md), [BR-28](../business-rules/BR-28.md), [BR-32](../business-rules/BR-32.md), [BR-41](../business-rules/BR-41.md) |

## Description

A customer views the items, address, amounts and payment of one of their orders.

## Preconditions

- The customer is signed in.

## Main Flow

1. The customer opens one of their orders.
2. The system returns the item snapshots, shipping address snapshot (BR-28), amounts, payment method and payment status.
3. If the order uses VietQR, is `Unpaid`, not `Canceled` and its payment deadline has not passed, the system also shows the VietQR code again with the deadline (BR-32, BR-41).

## Alternative Flows

- **A1. Order of another user**: At step 1, the system returns 404 Not Found (BR-08).
