# UC-49: Set Featured

| Field | Value |
|---|---|
| ID | UC-49 |
| Feature | APRD-05 |
| Group | Product Management |
| Actor(s) | Admin, Staff |
| Data | Products |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-15](../business-rules/BR-15.md) |

## Description

Staff mark or unmark a product as featured on the home page.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user toggles Featured on a product.
2. The system saves `IsFeatured`.

## Alternative Flows

- None.

## Postconditions

- The product appears in, or disappears from, Featured Products (UC-19).
