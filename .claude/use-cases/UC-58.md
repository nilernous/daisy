# UC-58: Create / Update Voucher

| Field | Value |
|---|---|
| ID | UC-58 |
| Feature | AVOU-01 |
| Group | Voucher Management |
| Actor(s) | Admin |
| Data | Vouchers |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-25](../business-rules/BR-25.md) |

## Description

An Admin creates or edits a voucher: type, value, maximum discount, minimum order, usage limit and period.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin opens the voucher form (new or existing).
2. The Admin enters code, name, discount type, value, maximum discount, minimum order amount, usage limit, start and end.
3. The system validates the voucher (BR-25).
4. The system saves the voucher.

## Alternative Flows

- **A1. Duplicate code**: At step 3, the system rejects the change.
- **A2. Invalid values**: At step 3, the system rejects the change (e.g. percent above 100, end before start).
- **A3. Usage limit below used count**: At step 3, the system rejects a limit lower than `UsedCount`.

## Postconditions

- The voucher is saved.
