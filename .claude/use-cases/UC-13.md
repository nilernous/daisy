# UC-13: View Categories

| Field | Value |
|---|---|
| ID | UC-13 |
| Feature | CAT-01 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Categories |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-13](../business-rules/BR-13.md) |

## Description

A visitor browses the category tree.

## Preconditions

- None.

## Main Flow

1. The visitor opens the category menu.
2. The system returns active categories as a parent/child tree, ordered by `SortOrder` (BR-13).

## Alternative Flows

- None.
