# UC-12: Set Default Address

| Field | Value |
|---|---|
| ID | UC-12 |
| Feature | PROF-05 |
| Group | Profile & Address Book |
| Actor(s) | Customer |
| Data | UserAddresses |
| Business rules | [BR-08](../business-rules/BR-08.md), [BR-09](../business-rules/BR-09.md) |

## Description

A customer chooses which address is preselected at checkout.

## Preconditions

- The customer is signed in and has at least one address.

## Main Flow

1. The customer selects one of their addresses and chooses Set as default.
2. In one transaction, the system clears the current default and marks the selected address as default (BR-09).
3. The address book shows the new default first.

## Alternative Flows

- **A1. Address of another user**: At step 1, the system returns 404 Not Found (BR-08).

## Postconditions

- Exactly one address of the customer is the default.
