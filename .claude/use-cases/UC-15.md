# UC-15: Product Detail

| Field | Value |
|---|---|
| ID | UC-15 |
| Feature | CAT-03 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Products, ProductVariants, ProductImages |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-14](../business-rules/BR-14.md), [BR-16](../business-rules/BR-16.md), [BR-17](../business-rules/BR-17.md) |

## Description

A visitor views full product information: gallery, sizes/colors, price, stock and rating.

## Preconditions

- None.

## Main Flow

1. The visitor opens a product by its slug.
2. The system returns name, brand, description, material, image gallery (BR-16), average rating and review count.
3. The system returns the active variants with size, color, price (BR-14) and stock status (BR-17).
4. The visitor selects a size and color to see that variant's price and stock.

## Alternative Flows

- **A1. Product not found or hidden**: At step 2, the system returns 404 Not Found.
- **A2. Variant out of stock**: At step 4, the variant is shown as unavailable and cannot be added to the cart.
