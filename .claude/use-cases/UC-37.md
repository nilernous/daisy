# UC-37: Order History

| Field | Value |
|---|---|
| ID | UC-37 |
| Feature | ORD-01 |
| Group | My Orders |
| Actor(s) | Customer |
| Data | Orders |
| Business rules | [BR-08](../business-rules/BR-08.md) |

## Description

A customer views their orders, newest first.

## Preconditions

- The customer is signed in.

## Main Flow

1. The customer opens My Orders.
2. The system returns a page of the customer's orders, newest first, each with `OrderCode`, date, order status, payment status and total.

## Alternative Flows

- **A1. No orders**: At step 2, the system shows an empty list.
