# UC-32: Select Shipping Address

| Field | Value |
|---|---|
| ID | UC-32 |
| Feature | CHK-01 |
| Group | Checkout & Payment |
| Actor(s) | Customer |
| Data | UserAddresses, Orders |
| Business rules | [BR-08](../business-rules/BR-08.md), [BR-09](../business-rules/BR-09.md), [BR-28](../business-rules/BR-28.md) |

## Description

At checkout, a customer chooses a shipping address from their address book.

## Preconditions

- The customer is signed in and on the checkout page.

## Main Flow

1. The system shows the customer's addresses with the default address preselected (BR-09).
2. The customer keeps the default, picks another address, or adds a new one (UC-11).
3. The system uses the chosen address for the order snapshot when the order is placed (BR-28).

## Alternative Flows

- **A1. No address**: At step 1, the customer must add an address before continuing.
