# UC-50: Set Flash Sale

| Field | Value |
|---|---|
| ID | UC-50 |
| Feature | APRD-06 |
| Group | Product Management |
| Actor(s) | Admin |
| Data | Products |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-14](../business-rules/BR-14.md) |

## Description

An Admin sets a sale price and its start and end time for a product.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin opens the sale settings of a product.
2. The Admin enters sale price, start time and end time, or clears the sale.
3. The system checks the sale price is between 0 and the base price and the start is before the end (BR-14).
4. The system saves the sale.

## Alternative Flows

- **A1. Invalid sale**: At step 3, the system rejects the change.

## Postconditions

- The product shows the sale price while the sale is active (UC-22).
