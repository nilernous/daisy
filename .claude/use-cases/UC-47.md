# UC-47: Manage Variants

| Field | Value |
|---|---|
| ID | UC-47 |
| Feature | APRD-03 |
| Group | Product Management |
| Actor(s) | Admin, Staff |
| Data | ProductVariants |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-11](../business-rules/BR-11.md), [BR-12](../business-rules/BR-12.md), [BR-17](../business-rules/BR-17.md) |

## Description

Staff add, edit or hide product variants: SKU, size, color, extra price.

## Preconditions

- The user is signed in as Staff or Admin and the product exists.

## Main Flow

1. The user opens the variants of a product.
2. **Add / edit**: the user enters SKU, size, color, color hex, extra price, stock quantity and low-stock threshold; the system checks SKU and size/color are unique (BR-12) and stock is not negative (BR-17), then saves.
3. **Hide / show**: the user toggles a variant's visibility; the system saves `IsActive` (BR-11).

## Alternative Flows

- **A1. Duplicate SKU or size/color**: At step 2, the system rejects the change.
- **A2. Negative stock or threshold**: At step 2, the system rejects the change.

## Postconditions

- The product's variants are updated.
