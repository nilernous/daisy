# UC-43: Create / Update Category

| Field | Value |
|---|---|
| ID | UC-43 |
| Feature | ACAT-01 |
| Group | Category Management |
| Actor(s) | Admin, Staff |
| Data | Categories |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-12](../business-rules/BR-12.md), [BR-13](../business-rules/BR-13.md) |

## Description

Staff create or edit a category: name, slug, image, parent and sort order.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user opens the category form (new or existing).
2. The user enters name, slug, image, parent category and sort order.
3. The system checks that the slug is unique (BR-12) and the parent is valid (BR-13).
4. The system saves the category.

## Alternative Flows

- **A1. Duplicate slug**: At step 3, the system rejects the change.
- **A2. Invalid parent**: At step 3, the system rejects choosing the category itself or one of its descendants as parent.

## Postconditions

- The category is saved.
