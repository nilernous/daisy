# UC-28: Update Quantity

| Field | Value |
|---|---|
| ID | UC-28 |
| Feature | CART-03 |
| Group | Shopping Cart |
| Actor(s) | Guest, Customer |
| Data | CartItems |
| Business rules | [BR-19](../business-rules/BR-19.md), [BR-20](../business-rules/BR-20.md) |

## Description

A visitor changes the quantity of a cart line.

## Preconditions

- The line is in the visitor's cart.

## Main Flow

1. The visitor changes the quantity of a line.
2. The system checks that the quantity is at least 1 and not more than the available stock (BR-20).
3. The system saves the new quantity and shows the updated totals.

## Alternative Flows

- **A1. Quantity above stock**: At step 2, the system rejects the change and shows the available quantity.
- **A2. Quantity below 1**: At step 2, the system rejects the change; the visitor removes the line instead (UC-29).

## Postconditions

- The line has the new quantity.
