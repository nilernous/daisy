# UC-68: Order Statistics

| Field | Value |
|---|---|
| ID | UC-68 |
| Feature | DASH-02 |
| Group | Dashboard & Reports |
| Actor(s) | Admin |
| Data | Orders |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-40](../business-rules/BR-40.md) |

## Description

An Admin sees the number of orders per status.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin chooses a period.
2. The system returns the number of orders per status (BR-40).

## Alternative Flows

- None.
