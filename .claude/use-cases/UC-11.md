# UC-11: Add / Update / Delete Address

| Field | Value |
|---|---|
| ID | UC-11 |
| Feature | PROF-04 |
| Group | Profile & Address Book |
| Actor(s) | Customer |
| Data | UserAddresses |
| Business rules | [BR-08](../business-rules/BR-08.md), [BR-09](../business-rules/BR-09.md), [BR-28](../business-rules/BR-28.md) |

## Description

A customer adds, edits or deletes a shipping address.

## Preconditions

- The customer is signed in.

## Main Flow

1. **Add**: the customer enters receiver name, receiver phone, province, district, ward and street address; the system validates and saves the address.
2. **Update**: the customer selects one of their addresses, edits the fields; the system validates and saves.
3. **Delete**: the customer selects one of their addresses and confirms; the system deletes it.

## Alternative Flows

- **A1. Invalid input**: The system shows the field errors and saves nothing.
- **A2. Address of another user**: The system returns 404 Not Found (BR-08).
- **A3. Default address deleted**: The customer has no default address until one is set (BR-09).

## Postconditions

- Existing orders keep their own copy of the address (BR-28).
