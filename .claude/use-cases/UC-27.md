# UC-27: View Cart

| Field | Value |
|---|---|
| ID | UC-27 |
| Feature | CART-02 |
| Group | Shopping Cart |
| Actor(s) | Guest, Customer |
| Data | CartItems, ProductVariants |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-19](../business-rules/BR-19.md), [BR-21](../business-rules/BR-21.md) |

## Description

A visitor views their cart with current prices.

## Preconditions

- None.

## Main Flow

1. The visitor opens the cart.
2. The system returns each line with thumbnail, name, size, color, quantity, current price (BR-21), line total and selected flag.
3. The system shows the total of the selected lines.

## Alternative Flows

- **A1. Item unavailable**: At step 2, a line whose product or variant is hidden or out of stock is marked unavailable and cannot be checked out (BR-10).
- **A2. Empty cart**: At step 2, the system shows an empty cart.
