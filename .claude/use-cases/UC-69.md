# UC-69: Top Selling Products

| Field | Value |
|---|---|
| ID | UC-69 |
| Feature | DASH-03 |
| Group | Dashboard & Reports |
| Actor(s) | Admin |
| Data | Products, OrderItems |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-40](../business-rules/BR-40.md) |

## Description

An Admin sees the best-selling products.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin chooses a period and how many products to show.
2. The system returns the products with the highest sold quantity in the period (BR-40).

## Alternative Flows

- None.
