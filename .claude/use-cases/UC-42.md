# UC-42: View Product Reviews

| Field | Value |
|---|---|
| ID | UC-42 |
| Feature | REV-02 |
| Group | Review & Rating |
| Actor(s) | Guest, Customer |
| Data | Reviews |
| Business rules | [BR-39](../business-rules/BR-39.md) |

## Description

A visitor reads the reviews of a product.

## Preconditions

- None.

## Main Flow

1. The visitor opens the reviews of a product.
2. The system returns a page of visible reviews, newest first, each with reviewer name, rating, comment and date (BR-39).
3. The system shows the product's average rating and review count.

## Alternative Flows

- **A1. No reviews**: At step 2, the system shows that the product has no reviews yet.
