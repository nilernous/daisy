# UC-08: View Profile

| Field | Value |
|---|---|
| ID | UC-08 |
| Feature | PROF-01 |
| Group | Profile & Address Book |
| Actor(s) | Customer |
| Data | Users |
| Business rules | [BR-02](../business-rules/BR-02.md), [BR-08](../business-rules/BR-08.md) |

## Description

A customer views their personal information.

## Preconditions

- The customer is signed in.

## Main Flow

1. The customer opens the profile page.
2. The system returns full name, email, phone, gender, date of birth and avatar of the signed-in account.

## Alternative Flows

- None.

## Notes

- Password hash and tokens are never returned (BR-02).
