# UC-17: Filter Products

| Field | Value |
|---|---|
| ID | UC-17 |
| Feature | CAT-05 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Products, ProductVariants |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-14](../business-rules/BR-14.md) |

## Description

A visitor narrows the product list by category, price range, size, color, brand and gender.

## Preconditions

- None.

## Main Flow

1. The visitor chooses one or more filters: category, price range, size, color, brand, gender target.
2. The system returns active products matching all chosen filters. Price range uses the effective price (BR-14). A product matches a size or color if it has an active variant with that option.

## Alternative Flows

- **A1. No match**: At step 2, the system shows an empty result.

## Related Use Cases

- Can be combined with UC-16 and UC-18.
