# UC-65: Lock / Unlock Account

| Field | Value |
|---|---|
| ID | UC-65 |
| Feature | AUSR-03 |
| Group | User Management |
| Actor(s) | Admin |
| Data | Users |
| Business rules | [BR-03](../business-rules/BR-03.md), [BR-07](../business-rules/BR-07.md) |

## Description

An Admin locks or unlocks a user account.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin chooses Lock or Unlock on a user.
2. **Lock**: the system sets `Status = Locked` and revokes the user's refresh token (BR-03).
3. **Unlock**: the system sets `Status = Active`.

## Alternative Flows

- **A1. Locking own account**: At step 1, the system rejects the action so the Admin cannot lock themselves out.

## Postconditions

- A locked user cannot log in or refresh tokens.
