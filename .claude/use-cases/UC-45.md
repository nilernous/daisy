# UC-45: Create / Update Product

| Field | Value |
|---|---|
| ID | UC-45 |
| Feature | APRD-01 |
| Group | Product Management |
| Actor(s) | Admin, Staff |
| Data | Products |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-12](../business-rules/BR-12.md), [BR-14](../business-rules/BR-14.md), [BR-28](../business-rules/BR-28.md) |

## Description

Staff create or edit a product: category, name, slug, brand, description, material, gender and base price.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user opens the product form (new or existing).
2. The user enters category, name, slug, brand, description, material, gender target and base price.
3. The system validates the input, checks the slug is unique (BR-12) and the base price is valid (BR-14).
4. The system saves the product and updates `UpdatedAt`.

## Alternative Flows

- **A1. Duplicate slug**: At step 3, the system rejects the change.
- **A2. Base price below current sale price**: At step 3, the system rejects the change (BR-14).

## Postconditions

- The product is saved. Existing orders are not affected (BR-28).
