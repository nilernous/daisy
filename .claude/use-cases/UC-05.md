# UC-05: Forgot Password

| Field | Value |
|---|---|
| ID | UC-05 |
| Feature | AUTH-05 |
| Group | Authentication |
| Actor(s) | Guest |
| Data | Users |
| Business rules | [BR-05](../business-rules/BR-05.md) |

## Description

A guest requests an email with a time-limited link to reset their password.

## Preconditions

- The guest is not signed in.

## Main Flow

1. The guest enters their email.
2. The system finds the account by email.
3. The system generates a random reset token with an expiry time and stores it, replacing any previous token (BR-05).
4. The system emails a reset link containing the token.
5. The system shows a message that, if the email exists, a reset link has been sent.

## Alternative Flows

- **A1. Email not registered**: At step 2, the system sends no email but shows the same message as step 5.
- **A2. Email cannot be sent**: At step 4, the system logs the error and asks the guest to try again later.

## Postconditions

- The account has a valid reset token until it expires or is used.
