# UC-21: Best Sellers

| Field | Value |
|---|---|
| ID | UC-21 |
| Feature | CAT-09 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Products |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-15](../business-rules/BR-15.md) |

## Description

The home page shows the best-selling products.

## Preconditions

- None.

## Main Flow

1. The visitor opens the home page or the Best Sellers section.
2. The system returns active products with the highest `SoldCount` first (BR-15).

## Alternative Flows

- None.
