# UC-64: View User Detail

| Field | Value |
|---|---|
| ID | UC-64 |
| Feature | AUSR-02 |
| Group | User Management |
| Actor(s) | Admin |
| Data | Users, Orders |
| Business rules | [BR-07](../business-rules/BR-07.md) |

## Description

An Admin views a user's information and order history.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin opens a user.
2. The system returns the user's profile, role, status and a page of their orders, newest first.

## Alternative Flows

- **A1. User not found**: At step 1, the system returns 404 Not Found.

## Related Use Cases

- UC-65 Lock / Unlock Account
- UC-66 Change Role
