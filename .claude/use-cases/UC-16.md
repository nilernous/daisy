# UC-16: Search Products

| Field | Value |
|---|---|
| ID | UC-16 |
| Feature | CAT-04 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Products |
| Business rules | [BR-10](../business-rules/BR-10.md) |

## Description

A visitor searches products by keyword in name or brand.

## Preconditions

- None.

## Main Flow

1. The visitor enters a keyword.
2. The system returns a page of active products whose name or brand contains the keyword.

## Alternative Flows

- **A1. No match**: At step 2, the system shows an empty result.

## Related Use Cases

- UC-17 Filter Products
- UC-18 Sort Products
