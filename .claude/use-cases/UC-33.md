# UC-33: Apply Voucher

| Field | Value |
|---|---|
| ID | UC-33 |
| Feature | CHK-02 |
| Group | Checkout & Payment |
| Actor(s) | Customer |
| Data | Vouchers |
| Business rules | [BR-24](../business-rules/BR-24.md), [BR-25](../business-rules/BR-25.md), [BR-26](../business-rules/BR-26.md), [BR-27](../business-rules/BR-27.md) |

## Description

At checkout, a customer enters a voucher code and sees the discount.

## Preconditions

- The customer is signed in and has selected items for checkout.

## Main Flow

1. The customer enters a voucher code.
2. The system finds the voucher by code.
3. The system checks eligibility against the current selected subtotal (BR-26).
4. The system calculates the discount (BR-27) and shows the new total (BR-24).

## Alternative Flows

- **A1. Code not found**: At step 2, the system shows 'invalid voucher code'.
- **A2. Not eligible**: At step 3, the system shows the reason: inactive, not started, expired, below minimum order amount, or usage limit reached.
- **A3. Remove voucher**: The customer removes the applied voucher; the system recalculates the total without discount.

## Postconditions

- The voucher is applied to the checkout. It is checked again when the order is placed (BR-30).
