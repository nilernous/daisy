# UC-61: View All Reviews

| Field | Value |
|---|---|
| ID | UC-61 |
| Feature | AREV-01 |
| Group | Review Moderation |
| Actor(s) | Admin, Staff |
| Data | Reviews |
| Business rules | [BR-07](../business-rules/BR-07.md) |

## Description

Staff view all reviews and filter by product and rating.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user opens the review list.
2. The user filters by product, rating and/or visibility.
3. The system returns a page of matching reviews, newest first, including hidden ones.

## Alternative Flows

- **A1. No match**: At step 3, the list is empty.
