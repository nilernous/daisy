# UC-70: New Customers

| Field | Value |
|---|---|
| ID | UC-70 |
| Feature | DASH-04 |
| Group | Dashboard & Reports |
| Actor(s) | Admin |
| Data | Users |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-40](../business-rules/BR-40.md) |

## Description

An Admin sees the number of new customer registrations over time.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin chooses a period and grouping (day or month).
2. The system returns the number of new customers per day or month (BR-40).

## Alternative Flows

- None.
