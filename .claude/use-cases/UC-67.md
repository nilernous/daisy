# UC-67: Revenue Statistics

| Field | Value |
|---|---|
| ID | UC-67 |
| Feature | DASH-01 |
| Group | Dashboard & Reports |
| Actor(s) | Admin |
| Data | Orders |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-40](../business-rules/BR-40.md) |

## Description

An Admin sees revenue by day or month from completed orders.

## Preconditions

- The user is signed in as Admin.

## Main Flow

1. The Admin chooses a period and grouping (day or month).
2. The system returns revenue per day or month (BR-40).

## Alternative Flows

- **A1. No completed orders**: At step 2, all values are zero.
