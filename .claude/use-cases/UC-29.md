# UC-29: Remove Item

| Field | Value |
|---|---|
| ID | UC-29 |
| Feature | CART-04 |
| Group | Shopping Cart |
| Actor(s) | Guest, Customer |
| Data | CartItems |
| Business rules | [BR-19](../business-rules/BR-19.md) |

## Description

A visitor removes a line from their cart.

## Preconditions

- The line is in the visitor's cart.

## Main Flow

1. The visitor chooses Remove on a line.
2. The system deletes the line and shows the updated totals.

## Alternative Flows

- None.

## Postconditions

- The line is no longer in the cart.
