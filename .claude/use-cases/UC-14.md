# UC-14: Product Listing

| Field | Value |
|---|---|
| ID | UC-14 |
| Feature | CAT-02 |
| Group | Product Catalog |
| Actor(s) | Guest, Customer |
| Data | Products, ProductImages |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-14](../business-rules/BR-14.md) |

## Description

A visitor sees a paged list of products, optionally in one category.

## Preconditions

- None.

## Main Flow

1. The visitor opens the product list, optionally choosing a category.
2. The system returns a page of active products in that category (BR-10).
3. Each product shows name, thumbnail, effective price, base price when on sale (BR-14), and average rating.
4. The visitor moves between pages.

## Alternative Flows

- **A1. No products**: At step 2, the system shows an empty result.
