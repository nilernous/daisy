# UC-51: Update Stock

| Field | Value |
|---|---|
| ID | UC-51 |
| Feature | INV-01 |
| Group | Inventory |
| Actor(s) | Admin, Staff |
| Data | ProductVariants |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-17](../business-rules/BR-17.md) |

## Description

Staff update the stock quantity of a variant.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user selects a variant and enters the new stock quantity.
2. The system checks the quantity is not negative (BR-17).
3. The system saves the new quantity only if the stock has not changed since the user loaded it.

## Alternative Flows

- **A1. Negative quantity**: At step 2, the system rejects the change.
- **A2. Stock changed meanwhile**: At step 3, an order changed the stock in the meantime; the system rejects the change and shows the current value.

## Postconditions

- The variant has the new stock quantity.
