# UC-09: Update Profile

| Field | Value |
|---|---|
| ID | UC-09 |
| Feature | PROF-02 |
| Group | Profile & Address Book |
| Actor(s) | Customer |
| Data | Users |
| Business rules | [BR-08](../business-rules/BR-08.md) |

## Description

A customer updates their full name, phone, gender, date of birth and avatar.

## Preconditions

- The customer is signed in.

## Main Flow

1. The customer opens the profile form.
2. The customer changes full name, phone, gender, date of birth and/or uploads a new avatar.
3. The system validates the input.
4. If a new avatar is uploaded, the system stores the file and saves its URL.
5. The system saves the changes and updates `UpdatedAt`.

## Alternative Flows

- **A1. Invalid input**: At step 3, the system shows the field errors and saves nothing.
- **A2. Invalid avatar file**: At step 4, the system rejects files of an unsupported type or size.

## Postconditions

- The profile shows the new values.

## Notes

- The email cannot be changed here (BR-01).
