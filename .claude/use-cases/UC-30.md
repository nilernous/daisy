# UC-30: Select Items for Checkout

| Field | Value |
|---|---|
| ID | UC-30 |
| Feature | CART-05 |
| Group | Shopping Cart |
| Actor(s) | Guest, Customer |
| Data | CartItems |
| Business rules | [BR-19](../business-rules/BR-19.md), [BR-23](../business-rules/BR-23.md) |

## Description

A visitor chooses which cart lines will be checked out.

## Preconditions

- The visitor has at least one cart line.

## Main Flow

1. The visitor selects or deselects one line, or all lines.
2. The system saves `IsSelected` for the affected lines.
3. The system shows the total of the selected lines.

## Alternative Flows

- **A1. Unavailable line**: At step 1, a line marked unavailable cannot be selected.

## Postconditions

- Only selected lines are used at checkout (BR-23).
