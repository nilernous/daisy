# UC-26: Add to Cart

| Field | Value |
|---|---|
| ID | UC-26 |
| Feature | CART-01 |
| Group | Shopping Cart |
| Actor(s) | Guest, Customer |
| Data | CartItems |
| Business rules | [BR-10](../business-rules/BR-10.md), [BR-17](../business-rules/BR-17.md), [BR-19](../business-rules/BR-19.md), [BR-20](../business-rules/BR-20.md) |

## Description

A visitor adds a variant (size/color) to their cart; guests use a session cart.

## Preconditions

- The product and variant are active.

## Main Flow

1. The visitor selects a size and color and a quantity.
2. The system checks that the variant is active and has enough stock (BR-20).
3. If the cart already contains this variant, the system increases its quantity; otherwise it adds a new line (BR-19).
4. The line is stored under the user (signed in) or the session (guest), selected for checkout by default.
5. The system shows the updated cart count.

## Alternative Flows

- **A1. No variant selected**: At step 1, the visitor is asked to choose a size and color.
- **A2. Not enough stock**: At step 2 or 3, the system rejects the request and shows the available quantity.
- **A3. Product or variant hidden**: At step 2, the system rejects the request.

## Postconditions

- The cart contains the variant with the requested quantity.
