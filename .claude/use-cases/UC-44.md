# UC-44: Show / Hide Category

| Field | Value |
|---|---|
| ID | UC-44 |
| Feature | ACAT-02 |
| Group | Category Management |
| Actor(s) | Admin, Staff |
| Data | Categories |
| Business rules | [BR-07](../business-rules/BR-07.md), [BR-10](../business-rules/BR-10.md), [BR-11](../business-rules/BR-11.md) |

## Description

Staff show or hide a category in the storefront.

## Preconditions

- The user is signed in as Staff or Admin.

## Main Flow

1. The user toggles a category's visibility.
2. The system saves `IsActive`.
3. A hidden category no longer appears in the storefront (BR-10).

## Alternative Flows

- None.

## Postconditions

- The category is shown or hidden.
