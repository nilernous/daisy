# BR-38: Rating Aggregation

| Field | Value |
|---|---|
| ID | BR-38 |
| Category | Review & Rating |
| Enforced by | Application + Database (`CK_Products_Rating`) |
| Source feature(s) | REV-03 |
| Used by | [UC-41](../use-cases/UC-41.md), [UC-62](../use-cases/UC-62.md) |

## Rule

`Products.AverageRating` and `Products.ReviewCount` are calculated from the product's visible reviews only.

## Details

- They are recalculated whenever a review is created, hidden or shown again.
- `AverageRating` is between 0 and 5, rounded to 2 decimals; 0 when there are no visible reviews.
