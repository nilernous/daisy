# BR-34: Payment Status Transitions

| Field | Value |
|---|---|
| ID | BR-34 |
| Category | Checkout & Payment |
| Enforced by | Database (`CK_Orders_PaymentStatus`) + Application |
| Source feature(s) | CHK-06, AORD-05 |
| Used by | [UC-36](../use-cases/UC-36.md), [UC-57](../use-cases/UC-57.md), [UC-71](../use-cases/UC-71.md) |

## Rule

`PaymentStatus` can only change along the transitions below.

## Details

- `Unpaid` -> `Paid` (webhook or staff confirmation; sets `PaidAt`).
- `Unpaid` -> `Failed`.
- `Paid` -> `Refunded` (staff, after refunding the customer).
- `Refunded` is final.
