# BR-18: Wishlist Uniqueness

| Field | Value |
|---|---|
| ID | BR-18 |
| Category | Wishlist |
| Enforced by | Database (`PK_Wishlists`) |
| Source feature(s) | WISH-01 |
| Used by | [UC-23](../use-cases/UC-23.md), [UC-24](../use-cases/UC-24.md) |

## Rule

A wishlist belongs to a signed-in customer and contains each product at most once.

## Details

- Adding a product that is already in the wishlist has no effect and is not an error.
