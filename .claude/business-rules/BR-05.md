# BR-05: Password Reset Token

| Field | Value |
|---|---|
| ID | BR-05 |
| Category | Account & Access |
| Enforced by | Application (`Users.ResetPasswordToken`, `Users.ResetPasswordExpiresAt`) |
| Source feature(s) | AUTH-05, AUTH-06 |
| Used by | [UC-05](../use-cases/UC-05.md), [UC-06](../use-cases/UC-06.md) |

## Rule

A password reset token is a random value with an expiry time. It can be used once and is cleared after a successful reset.

## Details

- Requesting a new token replaces any previous token.
- The Forgot Password response is the same whether or not the email exists, so accounts cannot be discovered.
- A successful reset also revokes the refresh token.
