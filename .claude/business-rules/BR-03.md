# BR-03: Account Lock

| Field | Value |
|---|---|
| ID | BR-03 |
| Category | Account & Access |
| Enforced by | Database (`CK_Users_Status`) + Application |
| Source feature(s) | AUTH-02, AUSR-03 |
| Used by | [UC-02](../use-cases/UC-02.md), [UC-04](../use-cases/UC-04.md), [UC-65](../use-cases/UC-65.md) |

## Rule

An account has status `Active` or `Locked`. A `Locked` account cannot log in or obtain new tokens.

## Details

- Locking an account revokes its refresh token immediately.
- An access token issued before the lock remains valid until it expires, so access tokens must be short-lived (see BR-04).
- Unlocking sets the status back to `Active`; the user must log in again.
