# BR-13: Category Hierarchy

| Field | Value |
|---|---|
| ID | BR-13 |
| Category | Product Catalog |
| Enforced by | Application + Database (`FK_Categories_Parent`) |
| Source feature(s) | CAT-01, ACAT-01 |
| Used by | [UC-13](../use-cases/UC-13.md), [UC-43](../use-cases/UC-43.md) |

## Rule

Categories form a tree through `ParentCategoryId`. Categories at the same level are ordered by `SortOrder`.

## Details

- A category cannot be its own parent or a descendant of itself.
