# BR-29: Order Code

| Field | Value |
|---|---|
| ID | BR-29 |
| Category | Orders |
| Enforced by | Database (`UQ_Orders_OrderCode`) + Application |
| Source feature(s) | CHK-04, CHK-05 |
| Used by | [UC-34](../use-cases/UC-34.md), [UC-35](../use-cases/UC-35.md) |

## Rule

Every order has a unique `OrderCode` generated by the backend.

## Details

- The code is short and uses only uppercase letters and digits (no diacritics, spaces or special characters), because it is used as the VietQR transfer content and some banks shorten or normalize that content.
- The code is shown to the customer and used to find orders in the admin panel.
