# BR-11: Hide Instead of Delete

| Field | Value |
|---|---|
| ID | BR-11 |
| Category | Product Catalog |
| Enforced by | Application + Database (foreign keys from `OrderItems`) |
| Source feature(s) | APRD-02 |
| Used by | [UC-44](../use-cases/UC-44.md), [UC-46](../use-cases/UC-46.md), [UC-47](../use-cases/UC-47.md), [UC-59](../use-cases/UC-59.md) |

## Rule

Categories, products and variants are deactivated (`IsActive = 0`) instead of deleted once they are in use.

## Details

- Order items keep a foreign key to the variant, so a variant that has been ordered cannot be deleted.
- Users are locked instead of deleted (BR-03); vouchers are deactivated instead of deleted.
