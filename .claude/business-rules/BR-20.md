# BR-20: Cart Quantity Limits

| Field | Value |
|---|---|
| ID | BR-20 |
| Category | Shopping Cart |
| Enforced by | Database (`CK_CartItems_Quantity`) + Application |
| Source feature(s) | CART-01, CART-03 |
| Used by | [UC-26](../use-cases/UC-26.md), [UC-28](../use-cases/UC-28.md), [UC-31](../use-cases/UC-31.md) |

## Rule

The quantity of a cart line is at least 1 and cannot exceed the variant's current `StockQuantity`.

## Details

- Stock is checked again at checkout, because it may change while items sit in the cart.
