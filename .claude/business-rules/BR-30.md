# BR-30: Atomic Order Placement

| Field | Value |
|---|---|
| ID | BR-30 |
| Category | Checkout & Payment |
| Enforced by | Application (transaction) + Database (`CK_ProductVariants_Stock`, `CK_Vouchers_UsedCount`) |
| Source feature(s) | CHK-07 |
| Used by | [UC-34](../use-cases/UC-34.md), [UC-35](../use-cases/UC-35.md) |

## Rule

Placing an order runs as one transaction: everything below succeeds, or nothing is saved.

## Details

- Create the order and its items.
- Deduct `StockQuantity` of each variant.
- Increase `SoldCount` of each product.
- Increase `UsedCount` of the voucher, if any.
- Remove the ordered lines from the cart.
- Stock and voucher usage are updated atomically (conditional update or concurrency token), so two concurrent orders cannot both take the last item or the last voucher use.
