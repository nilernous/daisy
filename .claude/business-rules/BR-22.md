# BR-22: Guest Cart Merge

| Field | Value |
|---|---|
| ID | BR-22 |
| Category | Shopping Cart |
| Enforced by | Application |
| Source feature(s) | CART-06 |
| Used by | [UC-02](../use-cases/UC-02.md), [UC-31](../use-cases/UC-31.md) |

## Rule

When a guest logs in, the lines of their session cart are moved into their user cart.

## Details

- If the user cart already has the same variant, the quantities are added together, capped at available stock (BR-20).
- After the merge, no lines remain for the guest session.
