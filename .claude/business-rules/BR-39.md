# BR-39: Review Moderation

| Field | Value |
|---|---|
| ID | BR-39 |
| Category | Review & Rating |
| Enforced by | Application (`Reviews.IsVisible`) |
| Source feature(s) | AREV-02 |
| Used by | [UC-42](../use-cases/UC-42.md), [UC-62](../use-cases/UC-62.md) |

## Rule

Staff can hide a review that breaks the rules. Hidden reviews are not shown in the storefront and do not count in the rating, but stay in the database and can be shown again.
