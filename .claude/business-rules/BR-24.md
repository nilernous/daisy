# BR-24: Order Total Calculation

| Field | Value |
|---|---|
| ID | BR-24 |
| Category | Checkout & Payment |
| Enforced by | Application + Database (`CK_Orders_Amounts`, non-negative only) |
| Source feature(s) | CHK-03 |
| Used by | [UC-33](../use-cases/UC-33.md), [UC-34](../use-cases/UC-34.md), [UC-35](../use-cases/UC-35.md) |

## Rule

All order amounts are calculated by the backend; amounts sent by the client are ignored.

## Details

- `UnitPrice` = effective price at checkout (BR-14).
- `SubtotalAmount` = sum of `UnitPrice * Quantity` of all items.
- `DiscountAmount` = voucher discount (BR-27), never more than the subtotal.
- `TotalAmount` = `SubtotalAmount - DiscountAmount + ShippingFee`, never negative.

## Notes

- The database only checks that each amount is non-negative; it does not check the formula.
