# BR-25: Voucher Definition

| Field | Value |
|---|---|
| ID | BR-25 |
| Category | Voucher |
| Enforced by | Database (`UQ_Vouchers_Code`, `CK_Vouchers_DiscountType`, `CK_Vouchers_DiscountValue`, `CK_Vouchers_UsedCount`, `CK_Vouchers_Period`) |
| Source feature(s) | AVOU-01 |
| Used by | [UC-33](../use-cases/UC-33.md), [UC-58](../use-cases/UC-58.md) |

## Rule

A voucher must have a valid definition.

## Details

- The code is unique.
- The discount type is `Percent` or `Fixed`.
- The discount value is greater than 0; a `Percent` value is at most 100.
- `StartAt` is before `EndAt`.
- If `UsageLimit` is set, `UsedCount` can never exceed it.
- `MaxDiscountAmount` and `MinOrderAmount` cannot be negative.

## Notes

- The database does not yet reject negative `MaxDiscountAmount` or `MinOrderAmount`.
