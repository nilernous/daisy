# BR-04: Access and Refresh Tokens

| Field | Value |
|---|---|
| ID | BR-04 |
| Category | Account & Access |

| Source feature(s) | AUTH-02, AUTH-03, AUTH-04 |
| Used by | [UC-02](../use-cases/UC-02.md), [UC-03](../use-cases/UC-03.md), [UC-04](../use-cases/UC-04.md), [UC-66](../use-cases/UC-66.md) |

## Rule

Login issues a short-lived JWT access token and a refresh token. Each account holds one active refresh token at a time.

## Details

- The access token carries the user id and role.
- A refresh token is valid only until `RefreshTokenExpiresAt`.
- Refreshing issues a new access token and a new refresh token that replaces the old one.
- Logout clears the stored refresh token.
- Because only one refresh token is stored, logging in on a new device ends the session on the previous device.
