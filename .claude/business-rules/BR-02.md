## Rule

Passwords are never stored or returned in plain text. Only a salted hash (`Users.PasswordHash`) is stored.

## Details

- Hashing uses ASP.NET Core Identity `PasswordHasher<T>` (PBKDF2).
- Password hashes, refresh tokens and reset tokens are never included in any API response.
