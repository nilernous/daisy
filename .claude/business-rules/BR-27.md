# BR-27: Voucher Discount Calculation

| Field | Value |
|---|---|
| ID | BR-27 |
| Category | Voucher |
| Enforced by | Application |
| Source feature(s) | CHK-02, CHK-03 |
| Used by | [UC-33](../use-cases/UC-33.md) |

## Rule

The discount is calculated from the order subtotal.

## Details

- `Percent`: subtotal x `DiscountValue` / 100, capped at `MaxDiscountAmount` if set.
- `Fixed`: `DiscountValue`.
- The discount never exceeds the subtotal, so the total cannot become negative.
- The voucher does not reduce the shipping fee.
