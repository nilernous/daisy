# BR-37: Review Eligibility

| Field | Value |
|---|---|
| ID | BR-37 |
| Category | Review & Rating |
| Enforced by | Database (`UQ_Reviews_OrderItem`, `CK_Reviews_Rating`) + Application |
| Source feature(s) | REV-01 |
| Used by | [UC-41](../use-cases/UC-41.md) |

## Rule

A customer can review a product only from an item of their own `Completed` order, once per order item.

## Details

- The rating is a whole number from 1 to 5; the comment is optional, up to 1000 characters.
- The review's user and product are taken from the order item, not from the request.

## Notes

- The database does not check that the review's `UserId` and `ProductId` match the order item.
