## Rule

Every account has exactly one role: `Customer`, `Staff` or `Admin`. Each API endpoint and page is restricted to the roles below.

## Details

- **Guest** (not signed in): view catalog, use a session cart, register, log in, forgot / reset password.
- **Customer**: everything a guest can do, plus profile, address book, wishlist, checkout, own orders and reviews.
- **Staff**: category management, product / variant / image management, featured products, inventory, order management, payment status, review moderation.
- **Admin**: everything Staff can do, plus flash sales, voucher management, user management and the dashboard.
- New accounts are always created with the `Customer` role. Only an Admin can change a role.
