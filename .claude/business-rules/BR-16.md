# BR-16: Product Images

| Field | Value |
|---|---|
| ID | BR-16 |
| Category | Product Catalog |
| Enforced by | Application |
| Source feature(s) | APRD-04 |
| Used by | [UC-15](../use-cases/UC-15.md), [UC-48](../use-cases/UC-48.md) |

## Rule

Each product has at most one thumbnail image. Images are shown in `SortOrder` and can be linked to a color so the gallery changes when the customer picks a color.

## Details

- The thumbnail is used in product lists, cart and order snapshots.

## Notes

- The database does not enforce a single thumbnail per product.
- features.docx links images to a color, but `ProductImages` links them to a `VariantId` (one size + color).
