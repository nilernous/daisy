# BR-23: Checkout Eligibility

| Field | Value |
|---|---|
| ID | BR-23 |
| Category | Checkout & Payment |
| Enforced by | Application + Database (`Orders.UserId` is required) |
| Source feature(s) | CHK-04, CHK-05 |
| Used by | [UC-30](../use-cases/UC-30.md), [UC-34](../use-cases/UC-34.md), [UC-35](../use-cases/UC-35.md) |

## Rule

An order can be placed only by a signed-in customer, from selected cart lines, with a shipping address.

## Details

- At least one cart line must be selected.
- Every selected product and variant must be active and have enough stock.
- The shipping address must belong to the customer (BR-08).
